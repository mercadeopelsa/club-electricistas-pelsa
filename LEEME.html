¿Qué debes instalar?

Para seguir trabajando aquí no necesitas instalar nada ahora: se utilizaron Node.js y Git disponibles en el entorno, y se descargaron las dependencias en el proyecto. No se instalaron programas globales.

  • Desarrollo independiente: Node.js 24 LTS, que incluye npm, y pnpm para reproducir el archivo de versiones. Un editor como Visual Studio Code es opcional.
  • Servidor: Docker Engine con Compose y un proxy HTTPS, o Node.js 24 instalado directamente. IT decide la opción según su infraestructura.
  • SQLite: no requiere instalar otro servidor de base de datos.

Instalación de desarrollo

En una terminal dentro de la carpeta del proyecto:

npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm run setup
pnpm run admin
pnpm run dev

Para esta computadora ya hay dependencias, configuración y cuenta de demostración. Consulta el archivo ACCESO-LOCAL.txt entregado junto al proyecto. No ejecutes el demo sobre una base con clientes.

Google Drive

Desde la ficha de cada miembro, descarga el frente y reverso y guárdalos en una carpeta de Drive con acceso restringido al equipo autorizado. No hay conexión automática con Drive. Si la aplicación corre en un servidor, no puede escribir directamente en la carpeta sincronizada de tu PC. Conserva la base de datos y su clave fuera de carpetas de sincronización mientras la aplicación está funcionando; las copias de respaldo se realizan con el servicio detenido.

Entrega a IT

La guía INSTALACION-IT.md contiene la configuración de Docker, dominio, HTTPS, cuenta inicial, copias de seguridad, restauración y pruebas de aceptación. El archivo VERIFICACION.md detalla qué se probó y las limitaciones pendientes.

Pendiente para producción

  • Elegir el dominio definitivo antes de imprimir tarjetas o compartir QR.
  • Configurar HTTPS, respaldos y administradores reales.
  • Completar el aviso de privacidad institucional, canal de atención y plazo de conservación.
  • Importar los miembros existentes cuando esté disponible el Excel.
  • Confirmar los textos de beneficios y reemplazar la marca tipográfica aproximada por el logotipo oficial en SVG/PNG.

Netlify

Este paquete usa un servidor Node persistente y archivos locales. No basta con subir la carpeta React a Netlify para conservar el administrador y los documentos. Si se elige Netlify, se adaptará el backend a Functions y se conectará almacenamiento persistente externo. Documentación de Netlify Functions.
